## 一、西洋占星星盘（Natal Chart）

### 1.1 核心概念

本命盘是出生时刻天象的快照，由四层要素构成：

| 层次 | 说明 | 类比（东方术数） |
|------|------|------------------|
| 星座（Signs） | 黄道十二宫，各占 30°，共 360° | 十二地支方位 |
| 行星（Planets） | 太阳系天体在黄道上的位置 | 星曜（紫微） |
| 宫位（Houses） | 十二个生活领域（后天十二宫） | 十二宫位 |
| 相位（Aspects） | 行星间的角度关系 | 会刑冲合 |

另有两个关键轴点：

- **上升点（Ascendant, ASC）**：出生时东方地平线升起的星座，决定第一宫起点与整体气质（即"上升星座"）。
- **天顶（Midheaven, MC）**：出生时子午线最高点，决定第十宫（事业/名声）与人生成就方向。
- 下降点（Descendant, DESC）= ASC + 180°；天底（IC）= MC + 180°，互为对轴。

**元素特征（性格气质）：**

- 火象（白羊/狮子/射手）：热情、行动力、开拓与领导，直觉敏锐。
- 土象（金牛/处女/摩羯）：务实、稳重、物质安全感，责任感与耐力。
- 风象（双子/天秤/水瓶）：理性、交流、重视思想，社交与信息传播。
- 水象（巨蟹/天蝎/双鱼）：情感深沉、直觉强烈、共情力高。

**模式特征（行动方式）：**

- 开创（白羊/巨蟹/天秤/摩羯）：季节之始，发起与引领。
- 固定（金牛/狮子/天蝎/水瓶）：季节中段，稳定与坚持。
- 变动（双子/处女/射手/双鱼）：季节末尾，适应与转化。

### 1.5 相位（Aspects）

两行星黄经之差的角距关系。主相位（Major）：

| 相位 | 角度 | 常见容许度（Orb） | 含义 |
|------|------|-------------------|------|
| 合相 Conjunction | 0° | ±8°~10° | 能量融合，强烈凸显 |
| 六分相 Sextile | 60° | ±4°~6° | 机会与支持 |
| 四分相/刑 Square | 90° | ±6°~8° | 张力、冲突与挑战 |
| 三分相/拱 Trine | 120° | ±7°~8° | 和谐顺畅，天赋 |
| 冲相 Opposition | 180° | ±8°~10° | 对立、平衡需求 |

次相位：半六分 30°、半刑 45°、补八分 135°、梅花相 150°。

**计算方式**：两行星黄经角距 `d = |G1 − G2|`，若 `d > 180°` 取 `360° − d`；当 `|d − 相位角| ≤ 容许度` 时成立。

### 1.6 本命盘计算流程（面向实现）

```
输入：出生日期、出生时间、出生地经度/纬度、时区（含夏令时）
  → 1. 本地时间转 UTC（减时区偏移，处理夏令时边界）
  → 2. 计算儒略日 JD（Meeus 公式，公历）
  → 3. 查星历表（VSOP87 / JPL DE440 / Swiss Ephemeris）
        得到各行星黄经 longitude、速度（<0 为逆行 R）
  → 4. 计算宫位系统（Placidus / Koch / Equal / Whole Sign ...）
        得 ASC、MC 与十二宫宫头 cusps
  → 5. 黄经 → 星座：sign = floor(longitude / 30)，度 = longitude % 30
  → 6. 计算相位（逐对行星）
  → 7. 汇总生成星盘对象
```

**关键数学量：**

- 儒略日（Julian Day）：`JD = floor(365.25 × (Y+4716)) + floor(30.6001 × (M+1)) + D + B − 1524.5`（B 为格里历修正项，M/Y 对 1-2 月做年份回退调整）。注：该公式默认给出 0h UT 的 JD，带时刻时需将 UT 小时折算为小数日并入 D。
- 恒星时 → 天顶：`恒星时 × 15 + 经度` 得到的是 **RAMC**（赤经天顶，单位°）；MC 是其在黄道上的黄经，需再经 `MC = arctan( tan(RAMC) / cos ε )` 转换（同样需象限修正）。
- 上升点 ASC 公式（通用）：
  `ASC = arctan( cos(RAMC) / ( −( sin(RAMC)·cos ε + tan φ · sin ε ) ) )`
  其中 ε 为黄赤交角（约 23°26′），φ 为出生纬度，RAMC = 赤经天顶。反正切结果需按 RAMC 与分母符号做象限修正（补 180°/360°），否则可能偏离 180°。

### 1.7 推荐实现方案（JS/TS）

| 方案 | 类型 | 说明 |
|------|------|------|
| **@swisseph/node / @swisseph/browser** | 库 | Swiss Ephemeris 的社区维护 JS 移植（非 Astrodienst 官方），Node 与浏览器双版本；`julday` / `calculatePosition` / `calculateHouses` 一行出结果（方法名以 README 为准），Moshier 星历内嵌（离线可用，~250KB gz），可选加载完整 Swiss Ephemeris 文件达 JPL 精度 |
| astro.com / swisseph 免费星历 | 数据 | 手工核对用，swepha 页可查各行星每日位置 |

### 2.2 星座运势常用要素

- **幸运物**：幸运石、幸运日、幸运数字、幸运色、幸运地点（各星座不同，见网上通行版本）。
- **相容性（最佳搭配）**：
  - 同元素最合：火火（白羊/狮子/射手）、土土（金牛/处女/摩羯）、风风（双子/天秤/水瓶）、水水（巨蟹/天蝎/双鱼）。
  - 风助火、水润土等元素生扶：如白羊×双子/水瓶、金牛×巨蟹/双鱼。
  - 对冲/同模式易有张力：如白羊×天秤、金牛×天蝎、固定×固定（狮子×水瓶）。
- **三属性分类**：阳性（火+风，主动外放）、阴性（土+水，内敛接受）。

## 三、塔罗牌（Tarot）

### 3.1 牌组构成

塔罗共 **78 张**，分两大部分：

- **大阿卡纳（Major Arcana）**：22 张，象征人生核心原型与重大主题，解牌分析重点。
- **小阿卡纳（Minor Arcana）**：56 张，细化到具体生活领域，分**数字牌**与**宫廷牌**。

小阿卡纳四牌组（花色），各对应一大元素：

| 牌组 | 英文 | 元素 | 领域 | 阴阳 |
|------|------|------|------|------|
| 权杖 | Wands | 火 | 创造、行动、热情、事业冲劲 | 阳 |
| 圣杯 | Cups | 水 | 情绪、情感、关系、直觉 | 阴 |
| 宝剑 | Swords | 风 | 思考、沟通、冲突、决策 | 阳 |
| 星币 | Pentacles | 土 | 物质、金钱、工作、健康 | 阴 |

每牌组 **14 张** = 10 张数字牌（Ace 到 10）+ 4 张宫廷牌（侍从 Page / 骑士 Knight / 王后 Queen / 国王 King）。

**正位/逆位解读原则**：
- 正位（Upright）：能量顺畅流动，多代表积极、直接、明确的含义。
- 逆位（Reversed）：并非简单"负面"，而是能量的内敛、阻滞、需要调整的方向；对正位意义的反思与修正。常见读法：① 正位含义受阻/延迟；② 正位含义过度或走偏；③ 向相反方向修正。
- 逆位并不完全消极，可能是潜在的积极发展契机（能量转向内省）。

### 3.3 小阿卡纳要点（结构化摘要）

**数字牌规律**：
- **Ace**：本牌组主题的纯粹开端，永远代表正面力量。
- **2-9**：本组主题的不同侧面发展（如权杖：2 个人力量、3 领导力、4 兴奋、5 竞争；圣杯：2 结合、3 欢庆、4 倦怠、5 失落…）。
- **10**：主题推到逻辑结果（如圣杯 10 家庭之爱与圆满、宝剑 10 终结与低谷）。

**宫廷牌（人物角色/人生阶段）**：

| 宫廷牌 | 阶段 | 特质 |
|--------|------|------|
| 侍从 Page | 开始/学习 | 好奇、学习、讯息、初显 |

宫廷牌可代表：具体人物、问卜者自身某面向、或所处人生阶段。

### 3.4 常用牌阵（Spread）

牌阵定义每张牌的位置含义，是解牌的框架。

**① 单牌阵（1 张）**：每日指引 / 是-否 / 快速答案。

**② 三牌阵（3 张，最经典）**，常见读法：
- 过去 - 现在 - 未来（时间线）
- 状况 - 行动 - 结果（决策）
- 你 - 对方 - 关系（感情）
- 思想 - 感受 - 行动（自我探索）

**③ 凯尔特十字（Celtic Cross，10 张）**：最全面的经典牌阵。
1 现状 → 2 挑战/助力 → 3 意识/目标 → 4 潜意识/基础 → 5 过去 → 6 近期未来 → 7 你的态度 → 8 环境 → 9 希望与恐惧 → 10 最终结果。
解牌：先读十字部分(1-6)看当前，再读竖线(7-10)看发展。

**④ 其他常见牌阵**：
- 吉普赛十字（5 张）：感情专题（心态/现状/举措/环境/未来）。
- 六芒星（7 张）：过去/现在/未来 + 对策/环境/态度/结果。
- 马蹄（7 张）：全面分析（过去/现在/未来/建议/环境/阻碍/结果）。
- 关系牌阵（2-5 张）：双方立场与关系发展。
- 二择一（5-7 张）：两个选项的利弊。
- 年度牌阵（12 张）：每月运势。

### 3.5 洗牌与抽牌流程（面向实现）

```
1. 选定牌阵（定义位置含义）
2. 洗牌（程序可用随机数模拟；可结合提问时间做种子以可复现）
3. 切牌/抽牌：按牌阵所需张数从牌堆抽取（去重）
4. 决定每张正位/逆位（随机 50%，或按牌面方向）
5. 按位置解读（结合正逆位）
6. 综合牌与牌之间的呼应给出建议
```

**推荐实现**：大阿卡纳 22 张作为基础牌组（与现有 64 卦 22/小六壬六神结构类似），后续可扩展至 78 张；抽牌可复用现有"蓍草/铜钱"的随机思路（时间种子可复现、支持历史对比）。

### 4.2 类型定义草案（对齐现有 `types/index.ts`）

```typescript
/** 星盘面板 */
interface AstrologyPanel {
  ascendant: string;              // 上升星座
  midheaven: string;              // 天顶星座
  sunSign: string;                // 太阳星座
  moonSign: string;               // 月亮星座
  planets: Array<{ name: string; sign: string; degree: number; retrograde: boolean }>;
  houses: Array<{ house: number; sign: string; cusp: number }>;
  aspects: Array<{ p1: string; p2: string; type: string; angle: number; orb: number }>;
}

/** 塔罗面板 */
interface TarotPanel {
  deck: 'major' | 'full';         // 大阿卡纳 / 全套
  spread: string;                 // 牌阵名（单牌/三牌/凯尔特十字...）
  cards: Array<{ index: number; name: string; reversed: boolean; position: string }>;
  keywords: string[];             // 综合关键词
}
```

### 4.3 注意点

- **日期体系**：星座、星盘均以**公历（阳历）**为基准，与现有农历/干支体系（`src/data/lunar.ts`）互补而不冲突；UI 已有阳历输入，可直接复用。
- **时区与夏令时**：星盘计算必须处理时区偏移与夏令时边界（参考项目此前 `Date.UTC()` 修复经验）。
- **随机可复现**：塔罗抽牌、起卦随机建议与现有 `zaobi`（蓍草）一致，用时间/种子可复现，便于测试与历史比对。
- **算法可靠性**：星盘行星位置若手写算法难度大，优先引入成熟的 Swiss Ephemeris 移植库并对其输出做黄金测试（参照现有 `ziwei.test.ts` 标准案例模式）。
